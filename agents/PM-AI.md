# PM-AI Brief

**Purpose**
- App2 is a reusable template for .NET 8 Minimal API + React front-end projects.
- Reference implementation: LocationForm (https://github.com/Ira2222/LocationForm) showcases Entra ID + MSAL based on this template.

**Workflow**
1. Capture requirements → map to API + SPA tasks.
2. Ensure template lineage is recorded (`TEMPLATE_ORIGIN.md`) for each project.
3. Before hand-off, confirm CI success and artifacts (SBOM, Windows bundles) are produced.

**Backlog hygiene**
- Track security and compliance work (guardrails, ProblemDetails, SBOM) alongside features.
- Maintain documentation parity (`README`, `config/schema.yaml`, change logs).

**Stakeholder communication**
- Share CI badges and release artifacts to demonstrate readiness.
- Highlight reusable assets (scripts, agents pack) for new teams adopting the template.
